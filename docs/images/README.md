# Rastin-AI Logo

[`logo.png`](logo.png) is the README logo. Its wordmark was updated with the
built-in image generation tool while retaining the existing visual identity.

The edit brief was:

```text
Use case: text-localization
Asset type: existing repository README logo, edit target is the provided image.
Primary request: Replace only the previous large wordmark with the exact new project name 'Rastin-AI'.
Text (verbatim): 'Rastin-AI'; subtitle remains 'Production-Oriented AI Platform'.
Constraints: Preserve the existing left orchestration/network symbol, its document/gear/database/chat icons, navy blue and teal-green palette, plain white background, subtitle, landscape layout, and generous spacing. Use clean navy sans-serif typography consistent with the original wordmark. Render Rastin-AI exactly, with a hyphen and uppercase R, A and I. Remove all traces of the old wordmark. This is a project rebranding, not a visual redesign.
```
